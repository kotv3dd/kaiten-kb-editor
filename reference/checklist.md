# Чек-лист перед сдачей материала

Проходи по порядку. Если находишь нарушение — исправляй сразу в тексте, а не просто отмечай. После правок пройди чек-лист ещё раз для изменённых мест.

## 1. Соответствие редполитике Kaiten (reference/editorial-policy-summary.md)

- [ ] Ни одного предложения длиннее ~15 слов без крайней необходимости.
- [ ] Нет усилителей без доказательств («самый», «лучший», «наиболее») — либо есть факт/цифра, которая их подтверждает.
- [ ] Нет канцелярита и бюрократизмов («в целях», «осуществляется», «производится», «в рамках»).
- [ ] Нет плеоназмов («мобильное приложение для смартфонов» и т.п.).
- [ ] Нет оценочных суждений без опоры на факты («всем известно», «каждый сталкивался», «интересная статья»).
- [ ] Заимствования и жаргон по возможности заменены на русские аналоги (таск → задача, фича → функция), кроме случаев, где замена звучит нелепо или мешает пониманию.
- [ ] «Функционал» заменён на «функциональность».
- [ ] Модальные глаголы («нужно», «необходимо», «требуется») заменены на повелительное наклонение или глагол действия — кроме случаев про физическую возможность/долг.
- [ ] Нет пассивного залога без действующего лица — подлежащее на месте.
- [ ] Прямой порядок слов: подлежащее → сказуемое → дополнение, без инверсии.
- [ ] Нет журналистских штампов и клише («затронули вопросы», «как снег на голову», «плачевные последствия»).
- [ ] «Для того чтобы» сокращено до «чтобы» везде.
- [ ] «Вы» и «ваш» — со строчной буквы.
- [ ] Заголовки и подзаголовки — без точки в конце.
- [ ] Восклицательный знак не используется без явной эмоциональной необходимости.
- [ ] Длинное тире — как пунктуационный знак; короткое тире — только для диапазонов чисел/дней; дефис — только внутри слов.
- [ ] Кавычки «ёлочки» снаружи, "лапки" — только внутри ёлочек.
- [ ] Эмодзи — не более 2 и только если это уместно для формата (в статьях базы знаний эмодзи обычно не нужны вовсе, кроме статей-навигаторов).
- [ ] Списки оформлены по правилу: простое перечисление — через запятую; перечисление с придаточными или пошаговое — через точку с запятой, точка после последнего пункта.
- [ ] Если это самостоятельная статья (не правка фрагмента) — есть короткое вступление (лид) и вывод без нравоучений.

## 2. Соответствие стилю базы знаний (reference/kb-writing-style.md)

- [ ] Заголовок — назывной или вопрос, без точки.
- [ ] Есть лид с определением/контекстом в первом-втором предложении.
- [ ] Если функция не самоочевидна — есть краткое «зачем это нужно» и хотя бы один конкретный пример использования.
- [ ] Инструкция дана по шагам: действие → результат, глагол в повелительном наклонении.
- [ ] Важные нюансы и ограничения вынесены отдельно (подзаголовком или «Важно:» / «Обратите внимание:»), а не спрятаны в середине абзаца.
- [ ] Термины интерфейса написаны так же, как в самом продукте.
- [ ] Использовано «Кайтен» (кириллица), правильно просклонено падежно («в Кайтене», «из Кайтена», не «в Кайтен»).
- [ ] Если уместно — статья заканчивается блоком со ссылками на связанные статьи.

## 3. Буква «ё»

- [ ] В тексте нет ни одной буквы «ё» — только «е» (проверь и заголовки, и подписи к спискам/таблицам).

## 4. Ничего не добавлено от себя (актуально при редактуре присланного текста)

- [ ] Не придуманы новые функции, преимущества или сценарии использования, которых не было в исходном тексте или в проверенных фактах о продукте.
- [ ] Не сделаны маркетинговые выводы задним числом («стало удобнее», «упростили работу»), если этого не было в источнике.
- [ ] Правка ограничена присланным фрагментом — вся остальная статья не переписана без запроса.

## 5. Язык и лексика

- [ ] Нет маркетинговых слов, без которых можно обойтись: удобно, гибко, эффективно, мощный, современный, инновационный, понятный, удобнее, максимально, бесшовно, нативно, интуитивно.
- [ ] Нет повторов однокоренных или одинаковых слов подряд в соседних фразах.
- [ ] Использованы простые глаголы: показать, скрыть, выбрать, добавить, убрать, открыть, создать, найти — вместо канцелярских аналогов.
- [ ] Существительное заменено на глагол там, где это упрощает фразу («управление видами» → «выбирать и редактировать виды»).

## 6. Финальная читаемость

- [ ] Текст прочитан вслух целиком (или мысленно проговорён) — нет мест, где сбивается дыхание или теряется мысль.
- [ ] Каждое предложение содержит одну законченную мысль.
- [ ] Текст поймёт человек, который впервые открыл Kaiten.

## 7. Формат ответа пользователю

- [ ] При редактуре фрагмента — предложены 1–3 варианта правки, если улучшений несколько; если один вариант явно лучше — сказано прямо, без перечисления слабых альтернатив.
- [ ] При написании статьи с нуля — сохранена структура «лид → зачем → как → нюансы → (примеры) → ссылки/вывод».

Если хотя бы один пункт не выполнен там, где должен быть выполнен, — вернись к тексту и исправь, прежде чем отдавать результат.
